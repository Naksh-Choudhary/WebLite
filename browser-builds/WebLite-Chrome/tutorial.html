WELCOME TO WEBLITE 1.4

Use the web.
Not all of its weight.

WebLite is a one-click low-data layer for modern browsers. It trims optional heavy resources before they download and shows live, local page telemetry while you browse.

Quick toggle: Alt + Shift + L

01

Choose the right mode

BALANCED

Everyday mode

Blocks media requests, blocks web-font downloads, uses a safe system-font fallback for simple text, stops autoplay and trims third-party embeds. Images stay available. Smart motion control escalates on animation-heavy pages.

Best starting point
STUDY

Student mode

Keeps readable text and same-site diagrams while trimming cross-site images, autoplay media, web fonts, third-party embeds and distracting motion. Anything important can still be loaded once.

For study sessions and limited data
SAVER

Hotspot mode

Adds third-party image blocking, all-embed blocking and Motion Shield to freeze scripted animation loops.

More saving, less decoration
ULTRA

Maximum saving

Blocks images, media, web fonts and embeds, while Motion Shield freezes scripted visual loops. Main text, CSS and scripts remain available.

For tight data limits
CUSTOM

Your rules

Choose image scope, media, fonts, embeds, motion level and autoplay separately.

Fine-grained control

What happens when you switch it on?

1Capture baseline

WebLite records the current normal page’s request count and browser-observed resource size before any blocking begins.

→
2Add network rules

The browser receives tab-scoped blocking rules for the selected categories.

→
3Reload lighter

The page reloads so blocked resources are stopped before they download.

→
4Compare

WebLite compares the lighter load with the saved normal baseline.

LIVE TELEMETRY

See the page change in real time.

The popup refreshes live measurements for observed page data, requests, cross-site resources, cookies, images, scripts, styles, fonts, media, frames, DOM nodes and load time. When a normal baseline exists, savings update while the lighter page loads.

COOKIE ACTIVITY

Count activity, not your data.

WebLite uses the browser’s cookie API to count cookies applicable to the current page, including HttpOnly cookies, and tracks cookie change events. Cookie names and values are never shown, stored by WebLite, or sent to a server.

WHY THE RELOAD?

Hiding is not saving.

If an extension hides a video after the browser has already downloaded it, the data is already gone. WebLite uses the browser's network-rule system first, then reloads so the request can be blocked before transfer.

WHAT DOES “MEASURED” MEAN?

No fake precision.

Browser Resource Timing does not expose exact byte sizes for every cached or cross-origin resource. WebLite therefore reports browser-observed data and measured savings instead of pretending to be an ISP-level data meter.

MEDIA GUARD

Pause the video, not just the tag.

WebLite blocks normal media requests, common streaming segment URLs, pauses media repeatedly, and intercepts scripted play() calls. This catches many sites that use blobs or JavaScript players.

MOTION SHIELD

Designed for animation-heavy pages.

CSS animations are cancelled directly. Saver and Ultra also suppress scripted animation-frame loops; Balanced can automatically escalate when a page contains lots of animations, videos or canvases.

LOAD ONCE

Blocked does not mean inaccessible.

When WebLite blocks a visible image, video, or embed, it leaves a compact placeholder. Choose Load once to allow that item for the current page load without turning WebLite off.

FONT SAFETY

Save font data without wrecking layouts.

WebLite blocks web-font downloads but only replaces fonts on simple text containers. Complex positioned or animated typography is left alone to prevent overlap and broken layouts.

03

When a page needs something WebLite blocked

Blocked video or image?

Use the small Load once button on its WebLite placeholder. The temporary exception clears on reload/navigation.

Images matter on this page?

Use Balanced instead of Saver/Ultra, or set Images to Keep.

Login/payment widget not showing?

Some services live inside third-party frames. Restore Normal for that page.

Protected page unavailable?

Browsers protect internal pages and their extension stores from normal extension modification.
