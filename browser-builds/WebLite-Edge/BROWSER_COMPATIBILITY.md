# Browser compatibility — Edge

WebLite 1.3.0 uses Manifest V3/WebExtensions APIs: storage, tabs, cookies, declarativeNetRequest, scripting, content scripts, and the toolbar action API.

- Protected browser pages and extension-store pages cannot be modified by normal extensions.
- Live data savings are browser-observed values, not ISP billing data.
- Load-once exceptions are temporary and are cleared on reload/navigation.
- Complex typography is deliberately not force-overridden; WebLite prioritizes layout safety over replacing every cached font.

This package has browser-specific manifest settings for Edge.
