# Contributing

WebLite is still a small hackathon project, so contributions do not need a complicated process.

If you find a bug:

1. mention the browser
2. mention the website where it happened
3. say which WebLite mode was active
4. describe what you expected
5. describe what actually happened

Screenshots are useful when the problem is visual.

For code changes, please keep the main idea of the project in mind: **saving data is not useful if the page becomes unusable.**

Small, understandable fixes are preferred over adding a large dependency for one feature.
